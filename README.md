# Student Management System

A Java-based web application for managing student records through an admin dashboard.

## Project Overview

The Student Management System allows administrators to manage student information efficiently. It supports student record management, searching, authentication, and MySQL database integration.

## Features

- Admin Login
- Admin Dashboard
- Admin Logout
- Add Student
- View Student Records
- Update Student Details
- Delete Student Records
- Search Students by Student ID, Name, or Department
- Session-based Admin Authentication
- Student Statistics
- MySQL Database Integration
- ## Technologies Used

- Java
- JSP
- Java Servlets
- JDBC
- MySQL
- HTML
- CSS
- Apache Tomcat
- Eclipse IDE
- MySQL Workbench

## Project Structure

src/main

## Database

The application uses MySQL for storing and managing student and admin information.

Main database tables include:

- student
- admin
- attendance
- marksdon
## How to Run

1. Clone the repository.
2. Import the project into Eclipse.
3. Configure Apache Tomcat.
4. Configure the MySQL database.
5. Update the database connection settings.
6. Start the Tomcat server.
7. Open the application in a web browser.

## Project Purpose

This project was developed to gain practical experience with Java web development, database connectivity, CRUD operations, authentication, and database-driven application development.
